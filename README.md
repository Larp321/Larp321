### Featured project

**[Neural network from scratch](https://github.com/Larp321/neural-network-from-scratch)** · **[Try the live demo](https://larp321.github.io/neural-network-from-scratch/)**

A deep-learning library written only with NumPy (no PyTorch or TensorFlow): dense and convolutional
layers, backpropagation, the Adam optimizer, dropout and L2, all checked with numerical gradient tests.

- **Kaggle Digit Recognizer: 0.99517**, about rank 246, with my own convolutional networks, trained without leaked data
- **98.4%** on MNIST handwritten digits, running live in the browser in plain JavaScript
- Generated training digits in **26 handwriting styles** MNIST misses: a European "1" went from 36% to 98%
- Profiled and fixed a hidden float32 → float64 slowdown: **2.6× faster** training
- 32 unit tests and CI on every push
